# 📊 Desafío de Estadística – Inferencia y Pruebas de Hipótesis

Resolución de un desafío práctico de **inferencia estadística**, utilizando **Python** para el análisis de datos y la validación de hipótesis mediante métodos estadísticos.
---

## 🎯 Objetivo del desafío

Aplicar conceptos de **estadística inferencial** para:
- Analizar características de una población a partir de una muestra.
- Formular y contrastar hipótesis estadísticas.
- Interpretar los resultados obtenidos con un nivel de confianza determinado.

---

## 🧠 Contexto del problema

A partir del registro de distintas características observadas en personas, se busca evaluar afirmaciones estadísticas sobre la población, utilizando pruebas de hipótesis y niveles de confianza para aceptar o rechazar dichas afirmaciones.

---

## 🧠 Conceptos estadísticos aplicados

- Estadística inferencial.  
- Hipótesis nula y alternativa.  
- Nivel de significancia.  
- Intervalos de confianza.  
- Pruebas de hipótesis.  
- Media poblacional.  

---

## 🛠️ Herramientas utilizadas

- Python  
- Pandas  
- NumPy  
- SciPy  
- Jupyter Notebook  

---

## 📊 Desarrollo del análisis

- Planteo de hipótesis nula y alternativa.  
- Cálculo de estadísticas muestrales.  
- Aplicación de pruebas estadísticas.  
- Evaluación de resultados según el nivel de confianza.  
- Interpretación de la aceptación o rechazo de las hipótesis.  

---

## 📌 Conclusiones

El desafío permitió aplicar técnicas de inferencia estadística para extraer conclusiones sobre una población a partir de datos muestrales, destacando la importancia del correcto planteo de hipótesis y de la interpretación de los resultados estadísticos.
